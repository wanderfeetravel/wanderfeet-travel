Política de Privacidad

Cómo usamos la información que compartes con WanderFeet Travel & Visa.

Información que podemos recibir

Podemos recibir datos enviados por formularios, WhatsApp, correo electrónico, Instagram u otros canales de contacto. Estos datos pueden incluir nombre, teléfono, destino, fechas de viaje, cantidad de viajeros, presupuesto, preferencias, información de pasaporte, documentos migratorios, datos para E-ticket RD o detalles necesarios para responder una solicitud.

Uso de la información

La información se utiliza únicamente para responder solicitudes, brindar asesoría, preparar cotizaciones, orientar procesos de visa, completar formularios solicitados, gestionar reservas o servicios pedidos por el cliente y mantener comunicaciones relacionadas con WanderFeet Travel & Visa.

No venta de datos

No vendemos ni alquilamos información personal. Los datos se tratan con confidencialidad y solo se usan para fines relacionados con la solicitud del cliente.

Proveedores externos

Ciertos datos pueden compartirse únicamente cuando sea necesario para el servicio solicitado, por ejemplo con aerolíneas, hoteles, aseguradoras, plataformas de reservas, proveedores de tours, traslados, eSIM, entidades gubernamentales, consulados, embajadas o servicios tecnológicos usados para comunicación y organización interna.

Herramientas, enlaces y cookies

El sitio puede incluir scripts, enlaces o herramientas de terceros y programas afiliados. Estos proveedores pueden utilizar cookies, parámetros de seguimiento o tecnologías similares para medir clics, visitas o conversiones. Al abrir enlaces externos, el usuario queda sujeto a la política de privacidad del proveedor correspondiente.

Seguridad y límites técnicos

El sitio está publicado en GitHub Pages y se accede mediante HTTPS. Actualmente los formularios del sitio abren WhatsApp con el mensaje preparado; la página no procesa pagos ni almacena datos sensibles en una base de datos propia desde el navegador. Aun así, el usuario debe evitar enviar información innecesaria y confirmar que usa canales oficiales de WanderFeet.

Derechos del usuario

El usuario puede solicitar corrección, actualización o eliminación de sus datos escribiendo a wanderfeetravel@gmail.com o contactando por WhatsApp. Algunas comunicaciones o registros pueden conservarse cuando sean necesarios para seguimiento, cumplimiento legal, comprobación de solicitudes o protección de derechos.
